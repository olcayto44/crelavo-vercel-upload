# Approved Website Builder artwork

Copy the four approved WebP files into this directory using these exact filenames:

- `website-builder-hero.webp`
- `business-website-concept.webp`
- `online-store-concept.webp`
- `creative-portfolio-concept.webp`

The build-time check in `next.config.mjs` automatically activates the gallery only when all four files exist. The five language variants already have localized descriptive alternative text. Keep the approved concept images intact; do not substitute unrelated imagery or present a concept as a completed customer project. After uploading, verify the files return image responses and rerun category acceptance.
