# Isolated Website AI job integration
Adds a durable one-claim job and owner-scoped SQL wrappers over existing atomic reserve/claim/record/finalize functions. AI-specific persisted approval includes plan and tariff digest. Provider response and rendered files stay in the job until matching reviewed cost evidence is supplied; ambiguous failures hold credits, never retry or refund automatically. Embedded PostgreSQL test uses synthetic receipt/cost evidence and real renderer/credit SQL, not a live provider or payment. This draft must not be applied to production: legacy writers, local/AI route exclusion, independently verified cost evidence, preflight-before-reserve, real DB concurrency and worker execution must be integrated and tested. No UI or live flags changed. English static site content only; no custom AI layout. No live DB mutation.
