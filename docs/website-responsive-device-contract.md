# Responsive device contract
Separate mobile (320–639), tablet (640–1023) and desktop (1024+) settings: columns, page gutters, section gap, headline and body font sizes. Bounds and strict parsing prevent arbitrary CSS; mobile remains one column. Existing candidate specs preserve previous behavior. Rendered candidate test fixtures include explicit device settings. Customer visual editor should expose the same validated schema, persistent settings and undo; this is not yet wired to the paid generator. Acceptance also includes actual device testing, zoom, keyboard, touch, screen reader and performance.
