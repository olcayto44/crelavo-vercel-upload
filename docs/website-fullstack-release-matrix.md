## Shared site configuration and subscription scope
The structured design now includes editable header announcement, optimized uploaded raster logo, footer text/navigation/contact/social visibility, business contact fields, and three separately enabled manual labeled sponsored slots. Safe HTTPS links only; no third-party ad scripts, ad network integration, tracking, scheduling or revenue handling. Settings are carried by the existing private design draft and revision mechanism, not live publishing. Added schema, renderer and browser tests; latest results pending. Full membership registration, entitlement enforcement, recurring billing, renewal/cancellation, commercial ad compliance and real asset library remain release gates.

## SEO/GEO management extension
The saved structured design now supports page-level focus/related keywords (editorial planning, not meta keywords), Open Graph and Twitter text, proposed social-image URL, canonical override, index/follow and sitemap inclusion preferences. Site-wide proposed HTTPS origin, site indexing and sitemap preferences produce a downloadable draft XML sitemap; excludes noindex and non-self-canonical pages. Every preview remains noindex,nofollow, robots.txt disallows crawling, and no public sitemap, canonical tag or external social image is emitted before verified publication. Customer designer includes approximate search snippet and basic warnings. Added smoke and browser interaction tests; final results pending. Publication-time canonical/sitemap/robots, verified domain, redirects, hreflang, sector-specific factual schema, media ALT, blog/product CMS SEO, Search Console integration and real AI content/keyword workflow remain acceptance gates.
