# Website full-stack release matrix (14 workstreams)
The user approved all workstreams; this is not a claim that all are complete. Do not activate production, billing or new external spending while tests are pending.
1. AI design/code: structured candidate only; real design provider dispatch and sandboxed arbitrary code missing.
2. Visuals: verified image rights and generated asset pipeline missing.
3. Editor: preview-only device settings, page metadata, drag/reorder, keyboard alternatives, undo and JSON export. Section text editing and per-device visibility are implemented in the pilot; new smoke/browser checks added, results pending. Persist and integrate with approved project.
4. CMS: isolated role-protected page draft edit and audit; blog/media/publish and real Auth browser test missing.
5. SEO/GEO: per-page semantic metadata/preview noindex; verified domain canonical/sitemap, facts and localized content gates remain.
6. Commerce/CRM/bookings: require domain-specific persistent workflows, inventory race tests, provider payments and verified refunds; not implemented.
7. Forms/email: real inbox, rate limit, consent, anti-spam, verified sending and delivery retry required.
8. Languages: five category locales, design candidate language setting; actual translated site content and hreflang verification missing.
9. Analytics: consent, tenant-scoped events, actual counts, conversion and data retention missing.
10. Hosting: isolated preview validated; authorized custom domain ownership, SSL, cost and deployment integration missing.
11. Backup: page revisions previously verified; prior content can now be loaded into an authenticated editor draft and explicitly saved as a new revision via the existing version fence. New browser/auth restore verification, transactional full-site snapshots and backup recovery tests remain.
12. Quality: 10 prior responsive tests, strict schema, RLS and version fence verified; real device, screen reader, CWV, auth/password protection, load and threat tests required.
13. Assistant/billing/delivery: real copy pilot and test ZIP; new design and CMS not yet connected to approval, ledger, Whop, delivery.
14. Commercial acceptance: require actual site, admin auth, real persisted edits, paid delivery, cost reconciliation and rollback in staging. No claims of competitor superiority until benchmarks.
