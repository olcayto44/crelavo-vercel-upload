# Website full-stack production acceptance v2

The first live-provider pilot validated content generation plus deterministic static files, not arbitrary code, functional CMS or commercial readiness. Keep production disabled. Website category scope in all five locales uses a single status registry; pilot is not commercial availability.

## Release stages
1. Versioned structured design contract, safe renderer and independent browser tests. Brand-specific layouts, image provenance and visual acceptance. No executable arbitrary AI code in the existing worker.
2. SEO/GEO and accessibility gates: per-page unique metadata, headings, language, linked navigation, real alt, factual schema and answer text, canonical and sitemap only for a verified deployment, no fake reviews/locations, no ranking guarantee. Test mobile 320/390, tablet 768, desktop 1024/1440, keyboard and overflow.
3. Functional tenant-isolated customer admin/CMS: owner and staff roles, persisted content/SEO/media, contact inbox, audit log, version history. No mock dashboard as a deliverable. Each business module (store/orders/payments/bookings/CRM/memberships) individually gated by verified integration and tests.
4. Exact pre-approval plan: pages, included capabilities and exclusions, limits, data/hosting/ownership, one-time credits and recurring fees, revision policy. Hash plan to approval and delivery proof. Full-stack generation must not use shared production keys or run untrusted code outside sandbox.
5. Real generated site acceptance and source ZIP, schema/migrations, environment example, setup guide; public deployment only after verified permissions and domain. Compare visual quality and function to alternatives with equivalent briefs. Crelavo main admin remains separate from the customer admin. No commercial release until real auth, payment, settlement, cost and browser tests pass.
