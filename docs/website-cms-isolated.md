# Isolated customer CMS foundation
Separate from Crelavo platform administration. Four tables (sites, membership, page drafts, revisions) and explicit grants/RLS. Owner/editor can edit assigned pages; viewer can read only; outsiders cannot see or modify other tenants. Membership provisioning is a trusted server-only operation. No anonymous site publishing, public forms, media, blog, domain or payments yet. Revision history is append-only for authenticated users; no direct audit writes. UI must use the isolated URL + publishable key and sign-in, never service role. Optimistic version check on the save RPC; direct permitted draft edits are also audited. The test database is disposable; do not copy production records. Test SQL roles simulate JWT context, not a real browser sign-in. Customer CMS release requires real Auth, editor and published snapshot tests.
